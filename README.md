# 中科院微电子所 2027 届就业攻略 · 单页操作手册

把《微电子所 27 届毕业生就业攻略》整理成一页可交互的 HTML 操作手册，用于毕业季各环节的时间管理与材料准备。

## 内容

| 模块 | 说明 |
|---|---|
| 一图总结 | 三个必填环节、领表三步流程、六条硬性规则、四个联系人、4 个关键数字 |
| 月度时间线 | 2026-09 → 2027-12 共 16 列，12 条阶段色条，点击查看该阶段任务/材料/地点/注意事项 |
| 方向详情 | 9 张卡片：三方就业、劳动合同、定向生、选调与公务员、博士后入站、出国升学、上海落户、盖章地点速查、毁约改派 |
| 任务清单 | 28 项分五段，勾选进度本地保存，可导出 Markdown |
| 表格模板 | 4 套可填写模板：就业推荐表、三方协议、接收函/上海落户/入站、毁约材料 |
| 关键时间节点 | 右上角常驻入口，含倒计时与最近现场办理日 |

## 部署

单文件静态页，无外部依赖（无 CDN、无字体、无脚本引用）。

- 仓库根目录的 `index.html` 即站点入口
- 适用于任意静态托管（EdgeOne Pages / GitHub Pages / Cloudflare Pages / 对象存储）

## 说明

- 数据来源为所内 2026-11 发布的就业攻略文档，请在办理前与群通知核对最新口径
- 原文中"本批次领取窗口"的年份存在 2027-10 与 2026-10 两处不一致，页面按原文保留并标注「原文口径」
- 时间线中带「推断」标签的 4 行（秋招高峰、春招补录、导师审核时段、领取窗口）为常规节奏推演，非原文明确表述
